2. **Activity**: A brief description of the activity that took place.
3. **Details**: Additional information or context about the activity.
4. **IP Address**: The IP address of the device or server where the activity was recorded.

### How This Portion of the Portal Works:
1. **Logging Activities**: When a user performs an action within the system, such as submitting a form, creating a new record, or interacting with a specific feature, the system logs this activity.
2. **Displaying Logs**: The 'Activity Log' section displays these logged activities in chronological order, allowing users to review their past actions.
3. **Filtering and Sorting**: Users can filter the logs by date, activity type, or IP address to find specific entries.
4. **Notification**: If no activity is recorded in the last seven days, a message is displayed indicating that no activity has been recorded during that period.

### Detailed Explanation:
- **Date/Time**: This column shows when the activity occurred, helping users understand the sequence of events.
- **Activity**: This column provides a brief description of what the user did, making it easy to identify the nature of the activity.
- **Details**: This column offers additional information or context, such as the specific task or document being worked on.
- **IP Address**: This column shows the device or server where the activity was recorded, which can be useful for troubleshooting or security purposes.

### Example of How This Works in Practice:
- **User Logs In**: When a user logs in, the system records this activity in the log.
- **User Submits a Form**: When a user submits a form, the system logs this action with the date and time, the type of activity (submitting a form), and the details of the form.
- **User Reviews Logs**: The user can review the activity log to see all their past actions, helping them understand their interactions with the system.

This section is crucial for maintaining transparency and accountability within the system, ensuring that users can trace their actions and understand the history of their interactions.
